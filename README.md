## Короткий опис

У межах практичного заняття було опрацьовано тему шаблонів і бібліотеки стандартних шаблонів STL.

У репозиторії подано дві програми:

1. **ConsoleApplication3** — програма, яка використовує контейнер `map<int, string>` для зберігання пар «номер місяця - назва місяця» та виведення назви місяця за введеним номером.
2. **ConsoleApplication4** — програма, яка використовує контейнер `map<string, string>` для реалізації простої телефонної книжки.
